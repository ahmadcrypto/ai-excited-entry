A colossal luminous jellyfish the size of a skyscraper rises out of a dark ocean at dawn — and a tiny lit coastal town, windows warm, is perched on top of its glowing bell, with long tentacles of soft light trailing into the deep. One bold silhouette, one impossible scale twist, under an aurora sky.

Made to get the AI judge excited: awe at first look, surprise in the scale, momentum in the rising bell and falling light, and a clean render with no text in the image at all.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies `entry.png` (1024×1024 JPEG bytes, 210,235 bytes) to `$MAKEFUN_OUTPUT_DIR/entry.png`. Two runs write byte-identical output.
